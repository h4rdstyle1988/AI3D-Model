# MANFRED Maintenance-Allowlist

Dieser Pfad ist ausschliesslich fuer eng begrenzte, versionierte Agent-Repairs
vorgesehen. Ein Skript wird nicht allein deshalb ausfuehrbar, weil es hier oder
unter `tools/documents-agent/` liegt. Zusaetzlich muessen Repair-ID, Zielagent,
Skriptpfad und Git-Blob im lokal installierten MANFRED-Runner fest eingetragen
sein.

Projekt-, CAD- und Produktaufgaben sowie beliebige Shell-Kommandos sind hier
nicht zulaessig. Neue Allowlist-Eintraege erfordern einen kontrollierten lokalen
MANFRED-Bootstrap mit Backup und Parsercheck.
