# Herbst-Igel – REF-CLEAN Autorisierung R06

Status: FREIGEGEBEN
Datum: 2026-08-30

Dies ist ausschließlich ein technischer Transport-Retry der vom Nutzer erneut hochgeladenen vollständigen Igelreferenz. Keine Produktanforderung wird geändert.

Die transportsichere Primärreferenz besteht aus vier UTF-8-Base64-Textteilen:
- `TASK-HERBST-IGEL-R02-REF-CLEAN-R04.part01.b64`
- `TASK-HERBST-IGEL-R02-REF-CLEAN-R04.part02.b64`
- `TASK-HERBST-IGEL-R02-REF-CLEAN-R04.part03.b64`
- `TASK-HERBST-IGEL-R02-REF-CLEAN-R04.part04.b64`

Exakt numerisch konkatenieren, dann einmal Base64 decodieren. Das Ergebnis muss sein:
- JPEG RGB
- 512 × 512 px
- 17.344 Byte
- SHA-256 `c1c9a5a094f1db2fd220f3433f83af8dedca780f56a4bf479eb8883432250859`
- strikter Decode PASS

Die 512×512-Datei ist eine proportionale technische Transportkopie des vollständigen Nutzeruploads. Sie ist nur die Trellis-Eingabe; Produktform und Optik bleiben durch den Nutzerupload verbindlich.

Alte beschädigte R03/R04/R05-Referenztransporte sind keine Formquelle. `REF-SEAM` bleibt ausschließlich für die Trennlinie autoritativ.
